# grace-runtime-rocm6

AMD ROCm 6 backend for [grace-runtime](https://github.com/ICAMS/grace-runtime), using the shared GRACE-1L/2L/3L kernels.

**Current PyPI packages are placeholders.** Once runtime wheels are published:

```bash
pip install grace-runtime-rocm6
```

The matching CPU package is installed automatically. Requires Linux x86-64 and system ROCm 6.2+.
See the [GPU manual](https://github.com/ICAMS/grace-runtime/blob/master/docs/backends.md#amd-rocm)
for supported cards, hardware validation, runtime requirements and source builds.
